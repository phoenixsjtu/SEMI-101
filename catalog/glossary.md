# 术语速查

| 术语 | 在半导体设备场景里的含义 |
| --- | --- |
| Tool / Module / Chamber | Tool 是整台设备，Module 是具备独立功能的模块，Chamber 是工艺发生的腔室。设备、模块和腔室编号的关系取决于机型。 |
| Lot / Wafer / Run | Lot 是批次，Wafer 是晶圆，Run 是一次处理记录。分析前先核对 run 的粒度，以及晶圆与设备、腔室的关联键。 |
| Recipe / Step | 配方给出处理步骤与设定值。相同信号在不同步骤可能对应不同物理过程，比较前先对齐步骤。 |
| Trace / Metrology | Trace 是按时间记录的设备信号。量测给出厚度、线宽、刻蚀深度等晶圆结果，常用于标定和验证模型。 |
| OES / RF | OES 指光发射光谱，可表征等离子体状态。RF 指射频，功率和匹配状态可用作设备与工艺输入。 |
| CFD / FEA | 计算流体力学和有限元分析。设备设计中可研究反应物流动、温度场、结构变形等问题。 |
| 代理模型 / 数字孪生 | 代理模型以较低计算成本近似高保真求解或实测响应。设备数字孪生还需要明确实体设备、数据关联、校准与验证方式。 |
| VM | 虚拟量测。用设备信号及工艺上下文估计本应由物理量测获得的结果。 |
| SPC / APC | SPC 用统计规则监测工艺波动。APC 涵盖根据量测或模型反馈调节工艺的控制策略。 |
| R2R | Run-to-Run 控制。用前序处理和量测更新后续 run 的配方设定，需考虑时延、限幅和设备状态变化。 |
| FDC / RCA | FDC 负责检测和分类故障。RCA 结合工艺、设备和维修证据定位可能的根因。 |
| PHM / RUL | PHM 指故障预测与健康管理。RUL 是到达约定失效标准之前的剩余时间或使用量。 |
| SECS/GEM / EDA | SECS/GEM 用于设备与主机通信和设备行为定义。这里的 EDA 指 Equipment Data Acquisition，即设备数据采集。 |
| RAM / EPT | RAM 指可靠性、可用性和可维护性。EPT 指设备性能跟踪，可为设备与模块的状态统计提供输入。 |
| MFC / ESC | MFC 是质量流量控制器。ESC 是静电卡盘，用于晶圆夹持，通常也与晶圆温控有关。 |
| RIE / ICP / CMP | RIE 是反应离子刻蚀，ICP 是感应耦合等离子体，CMP 是化学机械平坦化。 |
| PVD / CVD / ALD / ALE | 依次指物理气相沉积、化学气相沉积、原子层沉积和原子层刻蚀。 |

设备数据和状态相关标准见[设备运维](operations.md)。
