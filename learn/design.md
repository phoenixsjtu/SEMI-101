# 设备设计

一台新刻蚀设备的晶圆中心和边缘反复出现刻蚀深度差。下一轮原型该改进气结构，还是改静电卡盘的冷却流道？分别考虑反应物输运和晶圆温度，判断要测什么，才能把形貌差异和可修改的结构关联起来。本章读完后，你可以画出一张模型验证图，说明输入、输出和证据，还能判断什么时候值得用代理模型缩小候选范围。

## D1 腔室仿真

从设计决策倒推模型。比较喷淋头和多入口构型时，先把腔室几何、入口条件和壁面行为写成输入，确定要比较的是晶圆附近的输运分布、片内去除均匀性，还是周期时间。Yun 等人将气相 CFD 与表面反应的动力学蒙特卡洛耦合，对比了四种热原子层刻蚀腔室构型。评估刻蚀结果时，需要结合气体到达晶圆的时间、表面反应和各位置的暴露差异。[Yun 等人的腔室构型研究](https://doi.org/10.1016/j.compchemeng.2022.107757)

**练习**　画两张简化的腔室剖面图，标出进气、排气、晶圆和三个测点。给两种方案写下同一组比较指标，再指定一项实测量用于校验。若细化网格就改变了方案排序，先定位敏感区域，再比较构型。

## D2 设备数字孪生

把仿真和实验放到同一坐标系里。NIST 的实验型原子层沉积研究用吸收成像得到时变信号，为 CFD 提供前驱体入口波形。研究人员再对照模拟与实测中的到达时间、吹扫衰减和空间分布。这里的吸收信号用于比较归一化输运行为。若要预测绝对浓度，还需要独立的标定依据。[NIST 的前驱体输运数字孪生](https://www.nist.gov/publications/cfd-based-digital-twin-framework-transient-mocl5-transport-experimental-atomic-layer)

**练习**　在一页纸上画出「设备测量 → 模型输入 → 可对照输出 → 检验」的关系图。把用于确定入口波形的测量和留作独立检查的测量分开标记。若两个工况的到达时间吻合而吹扫尾段差异很大，你会先检查哪条边界条件或测量链路？

## D3 代理模型与设计优化

仿真预算有限时，可用低成本模型探索更多设计点，再用较少的高精度结果校正预测。Wang 等人将静电卡盘的冷却流道和表面凸点作为设计变量，用低、高保真热仿真建立晶圆温度场的代理模型。读案例时，关注误差在晶圆上的分布。平均温度预测得准，仍可能掩盖边缘热点。筛出候选后，可另做高精度仿真检查温差和热点位置，再决定是否进入原型验证。[Wang 等人的多保真静电卡盘优化](https://doi.org/10.1007/s11081-025-10059-0)

**练习**　写一张候选评审卡，列出可改变量、固定约束、均匀性指标和复核方式。假设两个候选的片内温差接近，其中一个冷却流道更复杂。写下你还需要什么证据，才愿意为它增加制造复杂度。
